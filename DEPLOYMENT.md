Go to https://console.cloud.google.com/apis/credentials\n   2. Create Credentials → API Key\n   3. Click the key → Application restrictions\n   4. Select \"HTTP referrers\"\n   5. Add:\n      - https://localhost:5173/*\n      - https://your-production-domain.com/*\n   6. API restrictions → select:\n      - Maps JavaScript API\n      - Places API\n      - Routes API\n   7. Save key value\n   ```\n\n   **Server Gemini Key:**\n   ```\n   1. Go to https://ai.google.dev/\n   2. Click \"Get API Key\" → Open in Cloud Console\n   3. Go to https://console.cloud.google.com/apis/credentials\n   4. Click the new key → Application restrictions\n   5. Select \"API restrictions\"\n   6. Search and select: \"Generative Language API\" only\n   7. Save key value (NEVER expose to browser)\n   ```\n\n4. **Test Locally**\n   ```bash\n   cp .env.example .env.local\n   # Add VITE_GOOGLE_MAPS_API_KEY and GEMINI_API_KEY\n   \n   npm install\n   npm run build\n   # Should complete without errors\n   \n   npm run dev\n   # Test at http://localhost:5173\n   ```\n\n---\n\n## Firebase Hosting + Functions (Recommended)\n\n### Why Firebase?\n- ✅ Native integration with Google Cloud\n- ✅ Firebase Functions for serverless backend\n- ✅ Firestore for authentication + saved places\n- ✅ Built-in SSL and global CDN\n- ✅ App Check for DDoS protection\n- ✅ Free tier available\n\n### Step 1: Create Firebase Project\n\n1. Go to https://console.firebase.google.com\n2. Click \"Add project\"\n3. Select your Google Cloud project\n4. Enable Firestore, Authentication, Functions, Hosting\n5. Note your **Project ID** (e.g., `milo-maps-abc123`)\n\n### Step 2: Install Firebase CLI\n\n```bash\nnpm install -g firebase-tools\nfirebase login\n```\n\n### Step 3: Initialize Firebase in Project\n\n```bash\nfirebase init\n```\n\nWhen prompted:\n- Select **Hosting, Functions, Firestore**\n- Choose **Use existing project**\n- Select your Firebase project\n- Public directory: `dist`\n- Configure as single-page app: **Yes**\n- Overwrite dist/index.html: **No**\n- Functions language: **JavaScript**\n- ESLint: **No**\n\n### Step 4: Configure Secrets\n\n```bash\n# Set Gemini API key as a secret (secure)\nfirebase functions:secrets:set GEMINI_API_KEY\n# Paste your Gemini API key when prompted\n\n# Set model (optional, defaults to gemini-2.5-flash)\nfirebase functions:secrets:set GEMINI_MODEL\n# Enter: gemini-2.5-flash\n```\n\n### Step 5: Create Environment File\n\n```bash\ncp .env.example .env\n```\n\nEdit `.env` and add:\n```bash\nVITE_GOOGLE_MAPS_API_KEY=your-browser-maps-key\n\n# Optional: Firebase config for auth + saves\nVITE_FIREBASE_API_KEY=your-firebase-api-key\nVITE_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com\nVITE_FIREBASE_PROJECT_ID=your-project-id\nVITE_FIREBASE_APP_ID=your-app-id\n```\n\n### Step 6: Deploy\n\n```bash\n# Build\nnpm run build\n\n# Deploy (hosting + functions + firestore rules)\nfirebase deploy\n\n# Or deploy specific services:\nfirebase deploy --only hosting  # Just hosting\nfirebase deploy --only functions  # Just functions\nfirebase deploy --only firestore:rules  # Just rules\n```\n\n### Step 7: Access Your Site\n\n```\nhttps://your-project-id.web.app\n```\n\n---\n\n## Vercel\n\n### Why Vercel?\n- ✅ Simplest setup (GitHub connect)\n- ✅ Global edge network\n- ✅ Automatic deployments on push\n- ✅ Easy environment management\n- ✅ Free tier available\n- 🔶 Need to add API route for Gemini backend\n\n### Step 1: Connect Repository\n\n1. Go to https://vercel.com/new\n2. Click \"Import Git Repository\"\n3. Select: `NextGenAILLC/milo-maps`\n4. Click \"Import\"\n\n### Step 2: Configure Build\n\nVercel should auto-detect:\n- **Framework:** Vite\n- **Build Command:** `npm run build`\n- **Output Directory:** `dist`\n- **Install Command:** `npm ci`\n\n(No changes needed)\n\n### Step 3: Add Environment Variables\n\nIn Vercel dashboard → Project Settings → Environment Variables:\n\n```\nVITE_GOOGLE_MAPS_API_KEY = your-browser-maps-key\nGEMINI_API_KEY = your-server-gemini-key\n\n# Optional: Firebase config\nVITE_FIREBASE_API_KEY = your-firebase-key\nVITE_FIREBASE_AUTH_DOMAIN = your-domain\nVITE_FIREBASE_PROJECT_ID = your-project-id\nVITE_FIREBASE_APP_ID = your-app-id\n```\n\n### Step 4: Deploy\n\nAutomatic on push to `main`. Manual:\n\n```bash\ngit add .\ngit commit -m \"config: production ready\"\ngit push\n```\n\n### Step 5: Add API Route (Optional)\n\nFor Gemini backend on Vercel, create `api/ask.ts`:\n\n```typescript\nimport type { VercelRequest, VercelResponse } from '@vercel/node';\n\nconst KEY = process.env.GEMINI_API_KEY || '';\nconst MODEL = process.env.GEMINI_MODEL || 'gemini-2.5-flash';\n\nexport default async (req: VercelRequest, res: VercelResponse) => {\n  // CORS headers\n  res.setHeader('Access-Control-Allow-Origin', '*');\n  res.setHeader('Access-Control-Allow-Methods', 'POST, OPTIONS');\n  res.setHeader('Access-Control-Allow-Headers', 'Content-Type');\n  \n  if (req.method === 'OPTIONS') return res.status(204).send('');\n  if (req.method !== 'POST') return res.status(405).json({ error: 'POST only' });\n\n  const { prompt, location } = req.body;\n  if (!prompt) return res.status(400).json({ error: 'prompt required' });\n  if (!KEY) return res.status(503).json({ error: 'GEMINI_API_KEY not configured' });\n\n  try {\n    const response = await fetch(\n      `https://generativelanguage.googleapis.com/v1beta/models/${MODEL}:generateContent?key=${encodeURIComponent(KEY)}`,\n      {\n        method: 'POST',\n        headers: { 'Content-Type': 'application/json' },\n        body: JSON.stringify({\n          contents: [{\n            role: 'user',\n            parts: [{ text: `You are Milo, a maps assistant. Query: ${prompt}` }]\n          }],\n          tools: [{ googleMaps: {} }, { googleSearch: {} }],\n          toolConfig: {\n            retrievalConfig: {\n              latLng: {\n                latitude: location.lat,\n                longitude: location.lng\n              }\n            }\n          }\n        })\n      }\n    );\n\n    const data = await response.json();\n    if (!response.ok) {\n      return res.status(502).json({ error: data?.error?.message || 'Gemini error' });\n    }\n\n    const text = data.candidates?.[0]?.content?.parts?.[0]?.text || '';\n    const sources = []; // Parse from grounding metadata\n\n    res.json({ text, sources });\n  } catch (error) {\n    res.status(500).json({ error: error instanceof Error ? error.message : 'Server error' });\n  }\n};\n```\n\n### Step 6: Access Your Site\n\n```\nhttps://your-project.vercel.app\n```\n\n---\n\n## Environment Variables Reference\n\n| Variable | Required | Type | Where | Value |\n|----------|----------|------|-------|-------|\n| `VITE_GOOGLE_MAPS_API_KEY` | ✅ | Browser | Env file | `AIzaSy...` from Google Cloud |\n| `GEMINI_API_KEY` | ✅ | Server | Secrets | `AIzaSy...` from ai.google.dev |\n| `VITE_FIREBASE_API_KEY` | ❌ | Browser | Env file | Firebase console |\n| `VITE_FIREBASE_AUTH_DOMAIN` | ❌ | Browser | Env file | `project.firebaseapp.com` |\n| `VITE_FIREBASE_PROJECT_ID` | ❌ | Browser | Env file | `milo-maps-abc123` |\n| `VITE_FIREBASE_APP_ID` | ❌ | Browser | Env file | Firebase console |\n| `GEMINI_MODEL` | ❌ | Server | Secrets | `gemini-2.5-flash` |\n| `PORT` | ❌ | Server | Env file | `8787` (local dev only) |\n\n---\n\n## Post-Deployment\n\n### 1. Go to https://console.cloud.google.com/apis/library\n   - Search \"Maps JavaScript API\"\n   - Click → Check status is \"Enabled\"\n   - Repeat for: Places API, Routes API, Geocoding API\n\n3. **Check key restrictions:**\n   - Go to https://console.cloud.google.com/apis/credentials\n   - Click your key\n   - Under \"API restrictions\": verify Maps APIs are selected\n   - Under \"Application restrictions\": verify domain matches\n\n4. **Check browser console:**\n   - Open DevTools (F12)\n   - Check Console tab for errors\n   - Look for 403 errors (permission denied)\n\n### Gemini Not Responding\n\n1. **Check API key is set:**\n   ```bash\n   # Firebase\n   firebase functions:secrets:list\n   \n   # Vercel\n   # Check Vercel dashboard → Settings → Environment Variables\n   ```\n\n2. **Verify Generative Language API enabled:**\n   - Go to https://console.cloud.google.com/apis/library\n   - Search \"Generative Language API\"\n   - Click → Ensure \"Enabled\"\n\n3. **Check billing account:**\n   - Go to https://console.cloud.google.com/billing\n   - Verify billing account is linked\n   - Check you have a valid payment method\n\n4. **Check server logs:**\n   ```bash\n   # Firebase\n   firebase functions:log\n   \n   # Vercel\n   # Dashboard → [project] → Deployments → [latest] → Functions → logs\n   ```\n\n### Firebase Deploy Fails\n\n```bash\n# Check project selection\nfirebase list\nfirebase use <project-id>\n\n# Check billing\nfirebase billing:list\n\n# Clear cache and retry\nfirebase logout\nfirebase login\nfirebase deploy\n```\n\n### Vercel Deploy Fails\n\n1. Check GitHub Actions logs in your repo\n2. Verify environment variables are set in Vercel dashboard\n3. Check build logs in Vercel dashboard\n4. Ensure `dist/` folder is created locally: `npm run build`\n\n---\n\n## Going Live Checklist\n\nBefore making public:\n\n### API Keys\n- [ ] Maps key created and restricted to production domain\n- [ ]
